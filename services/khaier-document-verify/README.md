# Khaier Document Verification Service

خدمة التحقق من الوثائق لنظام خير.

## Features

- Register documents through API.
- Generate short verification links.
- Public verification page.
- QR Code generation.
- PDF generation after mobile verification.
- HTML templates per association and document type.
- Basic admin page for templates.

## Security Notes

Do not commit secrets, passwords, tokens, or environment files.
Secrets must stay on the server only.
